1. Selling a pen.
When my clerk sells a pen, I need the system to:

Take a certain number of units off the shelf for that exact pen (brand, model, AND nib size — a Lamy Safari EF and a Lamy Safari M are different products to me).
If we don't have enough in stock, the sale should not go through, and the system should tell us that, not just pretend it worked.
Charge the customer whatever the current price is at the moment of sale — not some price from six months ago.
Write it all down: what was sold, how many, what it sold for, and when.

2. Restocking.
When a shipment comes in, I need to add units back to a pen's stock, and I need a record that says "we restocked X units of this pen on this date." I need to know how much inventory we're bringing in over time, not just what today's count is.

3. Returns.
Sometimes a customer brings a pen back. When that happens I need the units to go back onto the shelf, and I need a record of it — separate from a sale, because a return isn't the same event as a sale for my books.

4. Price changes.
When I decide to raise or lower a price, I need a record of both the old price and the new price, and when the change happened. I got burned once not knowing what something used to cost — never again.

5. Every single record needs, at minimum:

Which pen exactly (brand, model, nib)
What kind of event it was (sale, restock, return, price change)
How many units, if that applies
The price involved, if that applies
When it happened
Some kind of ticket/reference number so I can look any single event up later

6. I need to be able to save all this to a file and load it back, same as you did for my inventory — I don't want to lose my whole sales history every time we close for the night.

7. Down the line (not right now, but keep it in mind so you don't paint yourself into a corner): I'll want to ask things like "how many did we sell last month," "what's our best-selling pen," "show me every price change on the Pelikan M400." So don't design this so narrowly that answering those questions later becomes impossible.
